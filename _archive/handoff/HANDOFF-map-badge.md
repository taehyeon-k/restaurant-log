# Handoff: 기록 + 예정이 겹치는 곳, 그리고 잔 손질 셋

대상 저장소: `taehyeon-k/restaurant-log` (main)
전제: `wishes` 테이블, 가고싶다 화면, 위시 마커, WISH MET 경로가 이미 반영돼 있습니다.

## 1. 기록이 있는 곳을 또 갈 예정으로 담았을 때

**문제**: 지금은 같은 자리에 물방울 핀(기록)과 책갈피 핀(위시)이 **겹쳐 그려집니다.**

**규칙: 한 자리에 핀 하나.**

기본 모양은 **채운 물방울**(기록)입니다 — 다녀온 것은 이미 일어난 사실이고, 예정은 그 위에 얹힌 메모입니다.
그 물방울 **오른쪽 위에 작은 책갈피 배지**를 붙여 "또 갈 예정"을 표시합니다.

### 배지
- 15×15 원, 배경 `#fbfaf6`, `box-shadow:0 1px 3px rgba(28,26,23,.28)`
- 안에 9px 책갈피 (`fill:#b4552d`)
- 자리: 물방울 오른쪽 위 모서리. 물방울 크기(활성 30px / 평상 23px)에 따라 붙는 지점이 달라집니다 —
  `bottom: 8 + size - 8`, `margin-left: size/2 - 5` 로 계산했습니다.
- **인증마크가 붙는 자리(왼쪽 아래)와 겹치지 않습니다.**

### 위시 마커 쪽
**기록이 있는 곳의 위시는 책갈피 핀을 찍지 않습니다.** 배지로 이미 표시되므로 겹칩니다.
위시 마커를 붙일 때 기록 이름 집합으로 한 번 걸러내세요.

### 마커 필터
양쪽에 다 나옵니다 — 「기록만」에서는 배지 없는 물방울, 「가고싶다만」에서는 배지 붙은 물방울.
(즉 배지 판정은 필터와 무관하게 위시 존재 여부만 봅니다.)

### 갱신
핀 아이콘을 만들 때 예정 여부를 함께 넘기고, **활성 상태와 예정 여부 중 하나라도 바뀌면 아이콘을 다시 세우세요.**
마커를 처음 만들 때만 아이콘을 정하면, 예정을 담거나 지워도 배지가 붙거나 떨어지지 않습니다.

## 2. 기록 상세 · 가게 화면에 「또 갈 예정으로 담기」

지금 그 자리에 아이콘만 있는 50×50 단추를 두었더니 사용자가 못 찾았습니다.
**라벨이 붙은 전체폭 단추로 바꿉니다.**

- 「여기 또 왔어요 · 기록 추가」 **아래 줄**에 따로 놓습니다 (`margin-top:8px`)
- `width:100%; min-height:50px; border:1px solid #ded8cb; border-radius:18px`, 배경 없음, 13.5px `#1c1a17`
- 가운데 정렬, `gap:8px` — 14px 책갈피(`fill:#b4552d`) + **`또 갈 예정으로 담기`**
- hover에 테두리·글자 벽돌색
- 기록 상세와 가게 화면 둘 다 같은 모양

「기록 수정」은 그 아래로 내려갑니다. 세 단추의 순서: 기록 추가(짙은) → 또 갈 예정으로 담기 → 기록 수정.

검색 결과 시트의 「가고싶다에 담기」는 이미 있으니 그대로 둡니다.

## 3. 기록 상세 — 사진도 글과 함께 스크롤

**지금**: 사진(268px)과 사진 목록이 위에 고정돼 있고 글만 스크롤됩니다.
**바꿈**: 화면 전체가 하나의 스크롤이 되어 **사진도 위로 올라가 사라집니다.**

- 기록 상세 화면의 뿌리를 `flex-direction:column` + 내부 스크롤 대신 **`overflow-y:auto` 하나로** 둡니다
- 사진 블록, 사진 목록 띠, 글 블록에서 `flex-shrink:0` / `flex:1` / `overflow-y:auto` 를 모두 뺍니다
- **← 단추만 화면에 고정으로 남깁니다** — 스크롤 컨테이너 안에서 `position:absolute; top:50px; left:16px; z-index:3`,
  사진 밖으로 나가도 보이게 `box-shadow:0 2px 8px rgba(28,26,23,.14)` 추가

## 4. 위시 카드의 「수정」이 새 위시를 만들지 않게

담기 시트가 **새로 담기와 고치기를 겸합니다.** 편집 대상 id를 들고 있다가 저장 때 분기하세요.

- 고치기 모드: 제목 `담아둔 곳 고치기`, 저장 라벨 `고치기`, 모든 칸에 기존 값
- 저장하면 새 행을 만들지 않고 **그 위시를 갱신**
- 취소하면 편집 대상 id와 초안을 **함께** 비웁니다 (남아 있으면 다음 담기가 엉뚱한 위시를 덮어씁니다)
