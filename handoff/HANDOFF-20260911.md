## 1. 인증은 50m 안에서만

**적용 범위**: **촬영 후 «여기 어디예요?» 가게 선택 화면에만** 적용됩니다.
지도 + 단추로 직접 쓰는 기록, 보관함에서 꺼내 쓰는 기록에는 **거리 제한이 없습니다** —
인증마크 없이 쓰는 기록은 어디서든 쓸 수 있어야 합니다.

```ts
/* 이보다 먼 가게는 고를 수 없습니다 — 그 자리에 있었다는 증명이 인증의 값입니다 */
const PICK_MAX_M = 50;
```

현재 기기 오차를 보면 실제 기록이 30m 안에 잡힙니다. 여유를 두어 50m로 합니다.

### 후보 칸
- 50m를 넘는 후보: `opacity:.5`, 배경 없음, `cursor:default`, 누르기 불가
  부제 아래 10.5px `#a29a8c` — **「너무 멀어 고를 수 없습니다」**
- 맨 위 강조(벽돌색 테두리 + 그림자)는 **고를 수 있는 후보에게만** 줍니다.
  첫 칸이 50m 밖이면 강조하지 않습니다.
- 위치를 못 읽었으면 제한하지 않습니다(거리를 알 수 없으므로 전부 고를 수 있음).

### 50m 안에 아무것도 없을 때
목록 위에 안내 상자를 띄웁니다.
`border:1px solid #e2c9bb; background:#f9f0e9; border-radius:18px; padding:14px 16px`

- 12px `#6b665e` — "50m 안에 가게가 없습니다. 가게 앞에서 다시 찍으면 인증이 붙습니다."
- 그 아래 단추 **「인증 없이 기록만 남기기」**
  `min-height:44px; border:1px solid #ded8cb; border-radius:14px; background:#fbfaf6`, 12.5px
  → 촬영 흐름을 닫고 빈 기록 입력을 엽니다 (인증 없음)

**막다른 길을 만들지 마세요.** 인증을 못 받는 상황에서도 기록은 쓸 수 있어야 합니다.

## 2. 「여기 없어요 · 직접 찾기」 — 가게 찾기 화면

**지금 문제**: 이 단추가 촬영 흐름을 취소하고 메인 화면으로 돌아가 버립니다. 찍은 사진도 사라집니다.

**바꿈**: 흐름 안에 머무는 **가게 찾기 화면**을 엽니다. `z-[1450]`, 전체 화면.

### 머리 (`padding:46px 20px 14px`, 아래 테두리 `1px solid #e6e0d3`)
- ← 단추(44×44 원형, `margin-left:-10px`) + 제목 `가게 찾기` (Gowun Batang 18px 700)
- 검색 입력 — `min-height:48px; border-radius:16px; background:#fbfaf6`, 자리표시 `가게 이름`
- 안내 11.5px `#8a8377` — "인증은 50m 안에 있는 가게에만 붙습니다. 그보다 먼 곳은 인증 없이 기록으로 남길 수 있습니다."

### 목록
이름·분류·주소로 검색, **가까운 순**. 빈 검색어면 전체를 거리순으로 보여줍니다.
칸은 후보 목록과 같은 골격(거리 동그라미 34×34 + 이름 + 부제), 부제 아래 한 줄이 더 붙습니다.

- **50m 안** — 배경 `#fbfaf6`, 동그라미 `#f7ece5`/`#b4552d`, 안내 **「인증할 수 있습니다」**
  → 고르면 그 가게로 **인증 완료** 화면
- **50m 밖** — 배경 없음, 동그라미 `#f1ede4`/`#a29a8c`, 안내 **「50m 밖 · 인증 없이 기록됩니다」**
  → 고르면 이름이 채워진 **인증 없는 기록 입력**

### 목록에 없을 때
검색어를 입력했으면 맨 아래에 점선 단추:
**「'○○' 로 인증 없이 기록하기」** → 그 이름이 채워진 기록 입력

← 로 후보 목록으로 돌아갑니다. 사진은 유지됩니다.

## 3. 인증마크 — 물방울 핀 + 흰 원 + 벽돌색 체크

**지금**: 벽돌색 별(24각 starburst) 안에 흰 체크. 작아지면 체크가 뭉개집니다.

**바꿈**: **지도 핀과 같은 물방울**에 흰 원을 얹고 그 안에 벽돌색 체크를 넣습니다.
지도의 핀 어휘와 인증마크가 같은 계열이 됩니다.

```html
<!-- 바깥: 물방울 -->
<div style="display:grid; place-items:center; width:{S}px; height:{S}px;
            background:#b4552d; border-radius:50% 50% 50% 0;
            transform:rotate(-45deg); box-shadow:{그림자}">
  <!-- 안: 흰 원 (되돌려 회전) -->
  <div style="display:grid; place-items:center; width:{C}px; height:{C}px;
              border-radius:50%; background:#fbfaf6; transform:rotate(45deg)">
    <svg width="{K}" height="{K}" viewBox="0 0 24 24" fill="none" stroke="#b4552d"
         stroke-width="{W}" stroke-linecap="round" stroke-linejoin="round">
      <path d="M5 12.6L9.6 17.2L19 7.4"></path>
    </svg>
  </div>
</div>
```

크기표 (S 바깥 / C 흰 원 / K 체크 / W 선 두께)

| 쓰이는 곳 | S | C | K | W | 그림자 |
|---|---|---|---|---|---|
| 목록 썸네일, 그날 카드 | 24 | 15 | 9 | 3.6 | `1px -1px 4px rgba(28,26,23,.2)` |
| 보관함 썸네일 | 22 | 14 | 8.5 | 3.8 | `1px -1px 4px rgba(28,26,23,.2)` |
| 수정 화면 도장 줄 | 20 | 13 | 8 | 4 | 없음 |
| 기록 상세 사진 | 50 | 31 | 18 | 3 | `3px -3px 12px rgba(28,26,23,.26)` |
| 인증 완료 화면 | 52 | 32 | 19 | 3 | `3px -3px 12px rgba(28,26,23,.28)` |

물방울이 `rotate(-45deg)` 이므로 그림자 오프셋은 회전 뒤 아래로 떨어지도록 `x, -y` 로 줍니다.
**흰 원을 `rotate(45deg)` 로 되돌리지 않으면 체크가 비스듬히 눕습니다.**

**바꾸지 않는 것**: 지도 검색창 오른쪽의 라벨첩 단추 아이콘은 기존 별(도장) 모양 그대로 둡니다 —
그것은 인증마크가 아니라 라벨첩을 가리키는 표시입니다.

## 4. 보관함 단추를 서류철 모양으로

지도 오른쪽 위 보관함(임시저장) 단추가 **아직 카메라 아이콘**입니다. 기록이 모여 있는 곳이므로 **파일 폴더**로 바꿉니다.

```html
<svg width="23" height="23" viewBox="0 0 24 24" fill="none" stroke="#1c1a17"
     stroke-width="1.6" stroke-linecap="round" stroke-linejoin="round">
  <path d="M3 7.4V19a1.4 1.4 0 0 0 1.4 1.4h15.2A1.4 1.4 0 0 0 21 19V9.2a1.4 1.4 0 0 0-1.4-1.4h-7L10.4 5.2a1.4 1.4 0 0 0-1.1-.6H4.4A1.4 1.4 0 0 0 3 6v1.4Z"></path>
  <path d="M7.2 13.2h9.6"></path>
  <path d="M7.2 16.6h6"></path>
</svg>
```

탭이 달린 폴더에 글줄 두 개. 하단 탭의 카메라와 헷갈리지 않습니다.

## 5. 기록 상세 — 사진도 글과 함께 스크롤

지금은 사진과 사진 목록이 위에 고정돼 있고 글만 스크롤됩니다. **화면 전체가 하나의 스크롤**이 되게 합니다.

- 기록 상세의 뿌리를 `overflow-y:auto` 하나로 두고, 사진 블록·사진 목록 띠·글 블록에서
  `flex-shrink:0` / `flex:1` / `overflow-y:auto` 를 모두 뺍니다
- **← 단추만 고정으로 남깁니다** — 스크롤 컨테이너 안에서
  `position:absolute; top:50px; left:16px; z-index:3`, 사진 밖으로 나가도 보이게
  `box-shadow:0 2px 8px rgba(28,26,23,.14)`

## 6. 모바일/데스크톱 경계 — 아이패드 미니부터 데스크톱

`src/app/_components/Shell.tsx`

```ts
/**
 * 아이패드 미니(세로 744px)부터 데스크톱 화면, 그 미만은 모바일.
 * 높이 조건은 폴드 가로(841×673)를 모바일로 남기기 위한 것입니다 —
 * 아이패드 미니는 가로여도 높이가 744px라 데스크톱에 남습니다.
 * 지도 인스턴스가 두 개 생기지 않게 한쪽만 마운트합니다.
 */
const isMobile = useMediaQuery("(max-width: 743px), (max-height: 700px)");
```

기존 `(max-width: 820px)` 을 위 한 줄로 바꾸고 주석도 함께 고칩니다.

| 폴드 접음 | 344×882 | 모바일 |
| 폴드 폄 세로 | 673×841 | 모바일 |
| 폴드 폄 가로 | 841×673 | 모바일 (높이 조건) |

## 7. 명칭 바꾸기 — 캘린더 / 위시리스트

**UI에 보이는 글자만** 바꿉니다.

- `월력` → `캘린더`
- `가고싶다` → `위시리스트`

하단 탭 라벨, 화면 제목, 단추 라벨, 안내 문구, 빈 화면 문구, `aria-label`, `title`, `placeholder` 전부.
조사가 붙은 것도 자연스럽게:

- 「가고싶다에 담기」 → 「위시리스트에 담기」
- 「가고싶다 목록에서 보기」 → 「위시리스트에서 보기」
- 「가고싶다에 담아둔 식당」 → 「위시리스트에 담아둔 식당」
- 「기록에도 가고싶다에도 없는 이름입니다」 → 「기록에도 위시리스트에도 없는 이름입니다」
- 마커 필터 「가고싶다만」 → 「위시리스트만」

**바꾸지 않는 것**: 변수·함수·파일·타입·DB 컬럼명(`wish`, `wishes`, `plan_date`, `calendar` 등),
이미 영문인 eyebrow 라벨(`CALENDAR`, `WISHLIST`, `DISTRICTS`).

끝나고 `월력` 과 `가고싶다` 로 전체 검색해 UI에 남은 것이 없는지 확인하세요.
