# 붙여넣기용 프롬프트

아래 두 가지를 `taehyeon-k/restaurant-log` (main) 에 반영해 줘.
자세한 값은 같은 폴더의 HANDOFF-2.md 에 다 적혀 있고, 실제 화면은 DINARY Mobile.dc.html 을
브라우저에서 열어 지도 오른쪽 아래 카메라 버튼으로 폼을 띄우면 볼 수 있어.

1. 인증 마크를 톱니 별 clip-path 에서 밀랍 인장 인라인 SVG 로 바꾸기.
   HANDOFF-2.md 9번의 VerifiedMark 컴포넌트를 그대로 만들고,
   목록 카드 썸네일 모서리(26px, 고리 없음)와 기록 상세 사진 위(52px, 고리 있음)에 붙여 줘.
   그림자는 box-shadow 말고 filter: drop-shadow 로.

2. 모바일 기록 작성 폼을 HANDOFF-2.md 10번 명세대로 다시 짜기.
   칸 순서·크기·색·글꼴을 명세 그대로 맞추고, 반 별 입력·체감 가격 돼지·재방문 스위치·
   메뉴 여러 줄(줄별 가격, 합계, 추가/삭제)까지 동작하게. 저장 payload 규칙도 명세대로.

기존 색 토큰과 컴포넌트 구조는 유지하고, 새 라이브러리는 넣지 마.
